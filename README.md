# Customizable Totem Pop

Customize the Minecraft totem pop animation to match your personal style. This mod lets you tweak the appearance and behavior of the vanilla totem animation without changing gameplay.

## Features

### Toggle Animation
- Enable or disable the custom totem pop animation at any time.

### Position Adjustment
Move the animation anywhere on the screen.

- **X Offset** – Move the animation left or right.
- **Y Offset** – Move the animation up or down.

### Scale
Resize the totem animation.

- Make it smaller for a subtle effect.
- Make it larger for a more dramatic appearance.

### Opacity
Adjust how bright the animation appears.

- **0.0** – Fully dim.
- **1.0** – Vanilla full brightness.

### Animation Speed
Control how long the animation lasts.

- Values **greater than 1** make the animation slower.
- Values **less than 1** make the animation faster.

### Flip Options
Mirror the totem animation.

- **Flip Horizontal** – Mirror left ↔ right.
- **Flip Vertical** – Mirror top ↕ bottom.

## Configuration

All settings are available through the in-game configuration screen powered by **Cloth Config**.

Available settings:

| Setting | Description | Default |
|---------|-------------|---------|
| Enabled | Enable or disable the animation | `true` |
| X Offset | Horizontal position offset | `0.0` |
| Y Offset | Vertical position offset | `0.0` |
| Scale | Size multiplier | `1.0` |
| Opacity | Animation brightness | `1.0` |
| Duration Multiplier | Animation speed multiplier | `1.0` |
| Flip Horizontal | Mirror horizontally | `false` |
| Flip Vertical | Mirror vertically | `false` |

## Requirements

- Minecraft (compatible version matching the mod release)
- Fabric Loader
- Fabric API
- Cloth Config
